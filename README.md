# Villager Trade Unlocker

Unlock all villager trades instantly with this Fabric mod

## Features

- Unlocks all five trading levels for every villager
- Works with Minecraft Java Edition 1.21.4

## Requirements

- Minecraft Java Edition 1.21.4
- Fabric Loader 0.14.22 or later
- Java 17 or later

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/villager-trade-unlocker/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

Once installed, the mod will automatically unlock all villager trades when you interact with a villager.

## Configuration

The mod does not have any configuration options.
